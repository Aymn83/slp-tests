# الاختبارات الخاصة باضطرابات اللغة والكلام

منصة لتطبيق اختبارات اللغة والكلام إلكترونياً وإعداد تقارير قابلة للطباعة والتصدير PDF.

## التشغيل المحلي

```bash
npm install
npm run setup   # (بعد ضبط DATABASE_URL في .env) إنشاء الجداول + حساب المدير + الباقة الأساسية
npm run dev     # http://localhost:3200
```

بيانات دخول المدير الأول في ملف `.env` (`ADMIN_USERNAME` / `ADMIN_PASSWORD`). **غيّر كلمة المرور من «ملفي الشخصي» بعد أول دخول.**

## الأدوار والصلاحيات

- **المدير**: يوافق على طلبات العضوية أو يرفضها، وينشئ الحسابات مباشرة، ويوقف الحسابات، ويحدد لكل عضو باقة وتاريخ انتهاء، ويدير الباقات (أي الاختبارات تشملها كل باقة).
- **الفاحص**: يدخل حالاته ويطبّق الاختبارات المتاحة في باقته فقط. **لا يرى أحد حالات غيره، ولا حتى المدير.**

## إضافة اختبار جديد

1. أنشئ ملفاً في `src/tests/` على نمط `demo-articulation.ts`. يحتوي الملف على الأقسام والبنود وسلّم الإجابة ودرجاته ومستويات التفسير والتوصيات.
2. سجّله في `src/tests/index.ts`.
3. من صفحة «الباقات» أضِفه إلى الباقة المطلوبة.

## التقرير و PDF

زر «تصدير PDF» يفتح نافذة الطباعة باسم ملف جاهز؛ اختر «حفظ بتنسيق PDF». ينتج عن ذلك ملف PDF بنص عربي سليم وقابل للنسخ، مقاسه A4.

## قاعدة البيانات والنشر

قاعدة البيانات PostgreSQL محلياً وعلى السيرفر (`DATABASE_URL` في `.env`، والنموذج في `.env.example`).
خطوات النشر على `myskills.it` في [DEPLOY.md](DEPLOY.md)، والتحديث بعدها بأمر واحد على السيرفر: `/root/update-slp.sh`.
